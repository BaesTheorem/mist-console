model
Switches the active chat live when its backend is running (no restart), otherwise on your next message. New chats always start on Opus (1M).
permission mode
Controls how freely MIST acts. Live between default / accept edits / plan; a switch into or out of bypass restarts the backend on your next message.
thinking depth
How long MIST reasons before answering. Deeper costs more tokens and time. Applies to the active chat on your next message.

What fills this chat's context. Compacting replaces the history with a summary, so every later message re-bills far less.

while the mac is reachable
Off by default: the Mac keeps its Wi-Fi with the display asleep. Turn it on only if a network drops the Mac when the screen goes dark. Held on power only, never on battery.

mods

Claude Mods: plugins of function hooks loaded into every chat from mods/. They can draw panes, a band above the prompt, status lines and toasts here, intercept tool calls and add commands. Saving a mod reloads it in live chats. Ask MIST to write one (the /plugin-authoring skill).

claude flags

Spawn-time switches for the claude process behind each chat. A change applies when a chat's backend next starts (a new chat, or a dormant one waking).

workspace

mcp servers
