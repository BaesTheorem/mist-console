model
Switches the active chat live when its backend is running (no restart), otherwise on your next message. New chats always start on Opus (1M).
permission mode
Controls how freely MIST acts. Live between default / accept edits / plan; a switch into or out of bypass restarts the backend on your next message.
thinking depth
How long MIST reasons before answering. Deeper costs more tokens and time. Applies to the active chat on your next message.
context window
What fills this chat's context. Compacting replaces the history with a summary, so every later message re-bills far less.

Double-tap the Option (⌥) key to summon MIST from anywhere — even when she's closed (a tiny always-on background agent launches her). Needs macOS Accessibility permission for the agent (System Settings → Privacy & Security → Accessibility).

phone

Lets the MIST iPhone app, and any browser holding the pairing token, use this Console over the network. Off, the server answers this Mac only.
pair a phone
Scan it with the MIST app on the iPhone. Whoever holds this code can drive MIST, so treat it like a password. ·

away from home
A quick tunnel (cloudflared) gives the Mac a public https address while the Console runs. The address changes whenever the tunnel restarts; the phone re-learns it on this network, or through the discovery lookup when it is away.
A Tailscale MagicDNS name, or anything else that reaches this Mac from anywhere. Sturdier than the quick tunnel; needs Tailscale on both devices.
while the mac is reachable
This Mac drops its Wi-Fi when the display sleeps, which takes the phone's path and the tunnel with it. On power, the Console holds the display awake while remote access is on; on battery it never does.

routines

Edits write ~/.claude/scheduled-tasks (shared with the Claude desktop app). Enabling a schedule runs the routine from the Console via launchd. If the same routine is also scheduled in the desktop app, it will run twice — disable it there.
